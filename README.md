# 🦊 Охота на лис

Игра-поиск лис на поле с «пеленгом». Веб-приложение на Flask + клиентская
версия на чистом HTML/JS (играет прямо в браузере без сервера).

## Правила

- Лисы спрятаны на поле. Кликайте по клеткам, чтобы найти их.
- В открытой клетке показывается **пеленг** — сколько лис стоит на той же
  вертикали, горизонтали и обеих диагоналях.
- Если пеленг равен 0, вся вертикаль, горизонталь и обе диагонали этой клетки
  закрашиваются серым — там гарантированно нет лис.
- Попадание в клетку с лисой отмечает её как найденную.
- На игру даётся 100 ходов.

## Играть онлайн (GitHub Pages)

Откройте в браузере: https://it-ul.github.io/fox-hunter/

## Локальный запуск Flask-версии

```
pip install flask
python app.py
```

Затем откройте http://127.0.0.1:5000

Секретный ключ сессий задаётся переменной окружения `SECRET_KEY`
(см. `.env.example`).

## Структура

- `app.py` — Flask-версия игры
- `templates/index.html` — шаблон Flask-версии
- `docs/index.html` — автономная версия на HTML/JS для GitHub Pages
- `test_app.py` — тесты (7–8 штук, запуск: `python test_app.py`)
