Игра «Охота на лис» опубликована. Проект рабочий, тесты зелёные (18/18).
Идёт серия доработок (многопользовательский режим).

## Доработка 1: регистрация и вход игроков (2026-08-24)
- Пользователи: SQLite (`users.db`, таблица `users`, логин UNIQUE COLLATE NOCASE).
- Пароли: хэш `werkzeug.security` (scrypt) — в БД только хэш, проверено тестом.
- Страницы: `/register`, `/login`, `/logout` (POST), гостевое приветствие `/`.
- Игра доступна ТОЛЬКО после входа (декоратор `login_required` на /start, /move, /exit).
- Шаблоны: `base.html` + `welcome.html`, `login.html`, `register.html`;
  в `index.html` — панель игрока (имя + «Выйти»).
- Тесты: 18/18 (авторизация: регистрация/уникальность/валидация/хэш, вход, выход,
  доступ; игра — после входа). БД тестов — временный файл.
- Проверка живого сервера: гость→регистрация→вход→игра — все шаги OK.
- ВАЖНО: GitHub Pages (папка /docs) — статическая версия БЕЗ авторизации;
  многопользовательский режим работает только в Flask-версии (локально/на хостинге).

## Деплой (2026-08-24)
- **GitHub-репозиторий:** https://github.com/it-ul/fox-hunter (публичный)
